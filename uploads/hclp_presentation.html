Section 02
AI 에이전트 실습 트랙
4가지 에이전트로 업무 방식을 재설계하다
Research Agent

정보 수집 & 분석 에이전트

  • 시장 동향·경쟁사 정보를 자동 수집
  • 보고서 초안을 AI가 구조화하여 제공
  • 임원 의사결정용 요약 대시보드 생성
Writing Agent

문서 작성 & 커뮤니케이션 에이전트

  • 회의록·기안서·보도자료 자동 초안화
  • 어조·형식을 조직 스타일에 맞게 조정
  • 다국어 번역 및 요약 즉시 제공
Decision Agent

의사결정 지원 에이전트

  • 복잡한 시나리오 시뮬레이션 수행
  • 리스크·수익성 분석 자동화
  • 데이터 기반 대안 제시 및 추천
Process Agent

업무 프로세스 자동화 에이전트

  • 반복 업무 워크플로 자동 설계
  • 부서 간 협업 프로세스 AI 연결
  • 이메일·일정·승인 자동 처리
